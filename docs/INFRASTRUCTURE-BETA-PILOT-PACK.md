# Domains — pilot pack (one-pager)

**Offer:** Closed beta of DigitalGate Domains — search, connect (or gated register), DNS, Make it live for Gen 2 websites. SSL on the default path.

**You get:** Domains console + go-live with Websites.  
**Not yet:** Hosting/Deployments/Monitoring Apps, business mailbox, multi-provider DNS.

**Setup (staff):** Platform Dreamscape SOAP production env → Clients → **Enable Domains beta**. Keep **paid register** (`infra.domain_register`) off until intentional.

**Smoke:** Search → Connect domain → link Website → Apply DNS. Confirm console shows production SOAP (`/API-1.3`).
