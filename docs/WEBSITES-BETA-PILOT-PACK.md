# Website Builder — pilot pack (one-pager)

**Offer:** Closed beta of DigitalGate native websites — generate from your business profile, edit in Studio, publish, connect your domain. Optional WordPress **page content** import (not a theme clone).

**You get:** Sites + Studio + funnels v0 + Health + Domains go-live path.  
**Not yet:** Elementor recreation, Visual Studio, mailbox, fancy hosting console.

**Setup (staff):** Command Centre → Clients → **Enable Websites beta** → org completes checklist on `/apps/websites`.

**Smoke:** Create site → Studio edit → Preview/Publish → Domains Make it live.  
**WP path:** Plugin 10.70+ → Connectors → Studio WordPress tab → Import → review draft.

Full guide: [WEBSITES-BETA-LAUNCH.md](./WEBSITES-BETA-LAUNCH.md).
