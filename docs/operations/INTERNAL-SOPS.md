# Internal SOPs

**Status:** Index, not a dump

Platform Docs hold **how DigitalGate operates** at the company level. They are not the place for every script, every Clerk toggle, and every deploy note.

## Keep in Platform Docs (curated)

- Commercial process (how we sell Founding 10)
- Partner programme rules
- Customer onboarding / implementation / go-live / success
- Architecture, strategy, ADRs, App specs that constrain the product

## Keep in product or ops elsewhere

| Kind | Where |
|------|--------|
| Live customers, tickets, payouts | CRM, Partners UI, Commerce |
| Auth tenant settings | Clerk / infra runbooks (e.g. `docs/CLERK-AUTH-SETTINGS.md` — not catalogued unless promoted) |
| Historical Gate 1 dogfood | `docs/foundations/GATE-1-DOGFOOD.md` — closed internal alpha, not a customer SOP |
| Deploy / WP plugin | Engineering docs outside this allowlist |

Promote a file into the Command Centre catalogue only when staff should retrieve it via Platform Intelligence as approved truth.
