# Partner invite briefing

**Audience:** Ben / DigitalGate staff before sending Founding Reseller or Delivery Partner invites.  
**Status:** Operational briefing — not legal terms.

Use this so the first login matches what you promised. Both programmes are **invitation only**.

---

## Founding Reseller

### What they get on day one

| Surface | Expectation |
|---------|-------------|
| Invite → accept → claim | Works end-to-end |
| `/partner/dashboard` | Referrals summary + next actions |
| Warm intro + `/r/{code}` | Referral capture |
| `/partner/commissions` | Ledger UI; lines accrue from qualifying paid invoices when linked referrals convert |
| `/partner/terms` | Programme rules + **recorded acceptance** (still not solicitor-signed contracts) |
| Demo org | Show the product — not implement customers |

### What to say in the invite call / email follow-up

1. **You introduce. Ben closes. DigitalGate delivers.** You are not selling software or running implementation.
2. **Pending until staff approve** — accepting the invite starts setup; activation is not automatic.
3. **Commission is on qualifying Platform + App fees collected**, for the first N months per referred customer — not the whole customer invoice, not setup fees, not third-party spend.
4. **Payouts are manual for now** — Command ledger / bank transfer, not self-serve Stripe Connect for partners.
5. **Terms on `/partner/terms`** — please accept so we have a record. Binding legal pack still goes through solicitor when ready.

### Smoke before first wave

Invite → accept → approve → warm intro → open referral link → demo → accept terms → confirm commissions page loads (may be empty until a referred customer pays).

---

## Delivery Partner (Implementation)

### What they get on day one

| Surface | Expectation |
|---------|-------------|
| Invite → accept → claim | Works; lands in Delivery workspace |
| `/partner/delivery` | Dashboard, metrics, assigned projects |
| Projects / tasks / customers / training / QA / reports / activity | Live lists scoped to their portfolio (or manager view for leads) |
| Onboarding SOP | Same 15-stage framework as staff Command Delivery |
| Plans / documents | Honest hubs — scope and docs live on projects, not a separate CMS/vault |

### What to say

1. **Resellers introduce; Delivery delivers.** This is not a commission / reseller seat.
2. **You work assigned customers** (or all delivery work if Delivery Manager).
3. **DigitalGate owns the customer relationship, billing, and QA standard.**
4. Bookmark **`/partner/delivery`** — `/partner` routes deliverers there automatically; reseller dashboards are a different programme.

### Smoke before first wave

Invite → accept → assign a delivery project (owner or lead) → partner opens project detail → tasks / customers lists → onboarding SOP.
