# DigitalGate Visual Storytelling System

Status: Approved foundation · 2026-09-04

## Core direction

**RETAIN → ENRICH → SIMPLIFY.**

DigitalGate's established dark visual identity is canonical. Visual improvements must enrich the existing navy/black surfaces, blue/violet/green accents, Sora/Inter typography, gradients, glow and premium technical feel rather than replace them with a generic SaaS aesthetic.

## Primary principle

> **Show complexity visually. Explain only what the visual cannot.**

This sits beneath the product principle **Complex underneath. Simple on top.**

## Visual grammar

Use purposeful visual devices:

- connected nodes and signal paths for integrations/context;
- glowing intelligence loops for Connect → Understand → Advise → Act → Learn;
- closed-loop diagrams for Signal → Insight → Recommendation → Action → Outcome → Learning;
- human/living-system illustrations for Business Brain concepts;
- product UI frames when the real interface communicates better than an illustration;
- compact comparison panels for before/after and traditional/intelligent software;
- visual section breaks, timelines, process maps and metric cards;
- subtle motion for flow, causality, hierarchy and state.

Do not animate decoration simply because it can move. **No animation festival.** Motion must earn its electricity.

## Motion rules

1. Respect `prefers-reduced-motion`.
2. Prefer CSS transforms/opacity and SVG stroke animation.
3. Avoid autoplay video as explanation when a lightweight diagram works.
4. Motion should communicate direction, sequence, relationship or state.
5. Keep page performance and mobile rendering within the Definition of Done.

## Humour / voice

**Professional doesn't have to mean personality-free.**

Use occasional dry, intelligent humour as a reward for reading. Aim for zero to one strong moment per normal page; long Insights may support more where natural.

Good examples:
- “Your business has enough tabs open already.”
- “Some jobs really shouldn't require a human. Sending the same follow-up for the 437th time is one of them.”
- “Important information is usually somewhere. An inbox. A spreadsheet. Someone's head. Possibly Dave's head. Dave's on leave.”
- “If something already does its job brilliantly, DigitalGate would rather connect to it than rebuild it for sport.”
- “Because another chatbot floating in the bottom-right corner wasn't the breakthrough businesses were waiting for.”
- “Underneath, it's allowed to be an absolute monster. You shouldn't have to know.”

Never use humour in security warnings, financial/consequential actions, permissions, legal/compliance guidance, incidents or destructive confirmations.

## Reusable visual primitives

### Signal node
A compact icon/node with label, optional pulse and connection line.

### Intelligence rail
A horizontal/vertical sequence of stages with animated signal travel. Must collapse cleanly on mobile.

### Closed loop
Circular or returning-path diagram showing outcomes feeding learning and learning improving future interpretation.

### Living system map
Human/body silhouette or abstract anatomical system mapped to Business → Events → Data & Knowledge → Business Brain → Advisor → Automation → Communications → Governance → Outcomes & Learning.

### Product proof frame
Real DigitalGate UI inside a restrained browser/app frame. Prefer actual product screenshots to fabricated UI when the feature is live.

### Recommendation card
Shows Signal → Why it matters → Recommended action → owner control. Useful across public website and product.

## Page review gate

For each public page assess:

1. Message — can the value proposition be understood quickly?
2. Text density — what can be removed or visualised?
3. Hierarchy — is the important thing visually obvious?
4. Visual opportunity — what concept benefits from a diagram/product proof?
5. Credibility — are claims supported by real capability/proof?
6. CTA — is the next action clear and proportionate?
7. Mobile — does the story remain understandable on a narrow screen?
8. Performance/accessibility — does visual richness preserve usability?

## Rollout order

1. Connected Business Insights Parts 1–4.
2. Business Brain.
3. Automation.
4. Homepage / Platform / Apps / Growth.
5. Core and Growth app marketing pages.
6. Industry pages.
7. Remaining public website pages.

Every rollout should be measured against comprehension and conversion, not the number of graphics added.
