# Aida Intelligence capability matrix

Architecture and planning only. Audited 2026-10-09 against `origin/main` at `5a08e2f76b786d5a45c03565b3816bcf9574971c`. This is static repository evidence, not a production runtime certification. “Main” means merged source available for release; actual deployment, credentials, entitlements, migrations, source licences and live connectivity were not inspected. Production availability is therefore **unverified** throughout. No production database, provider or paid AI calls were made.

## Classification rules

- **IMPLEMENTED**: concrete code for the narrowly named capability exists on main; does not imply complete end-to-end intelligence or live activation.
- **PARTIALLY IMPLEMENTED**: code exists but target coverage, governance or integration is incomplete.
- **PLANNED**: documentation design exists without its runtime implementation.
- **MISSING**: no implementation for the named target was found in inspected paths; this is a bounded audit, not proof of absence from every historical branch.

Links below resolve on the pinned main baseline unless explicitly identified as PR links. Target designs are in [Architecture](AIDA-INTELLIGENCE-ARCHITECTURE.md); sequencing is in [Roadmap](AIDA-INTELLIGENCE-IMPLEMENTATION-ROADMAP.md).

## Audit limits and release interpretation

This matrix records code existence and inspected boundaries, not real customer metrics, live source permission, provider availability or release approval. PR bodies are attributed reports, not independent test results. Existing documentation is evidence of intention only. Main's approved-knowledge query does not itself enforce expiry; future design must not silently assume it does.
