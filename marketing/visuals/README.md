# DigitalGate marketing visual assets

The first visual rollout is intentionally built from lightweight, accessible HTML/CSS/SVG primitives inside the native Website Studio page content. This keeps the established dark theme, avoids heavy media dependencies and lets motion respect `prefers-reduced-motion`.

## First assets

### Insight 2 — Living system map
Visual target: a human silhouette / anatomical network mapping Business, Events, Data & Knowledge, Business Brain, Advisor, Automation, Communications, Governance and Outcomes & Learning.

### Insight 3 — Intelligence rail
Implemented in `marketing/pages/from-signal-to-action.html`.

- Connect → Understand → Advise → Act → Learn
- animated travelling signal on capable devices
- vertical mobile fallback
- reduced-motion fallback

### Insight 3 — Learning loop
Implemented in `marketing/pages/from-signal-to-action.html`.

## Illustration direction

Concept art generated during design exploration should be treated as art direction, not a replacement for the existing DigitalGate website. Final illustrations must use the current DigitalGate dark palette and be optimised for web delivery.

Do not introduce generic white SaaS layouts or unrelated stock imagery.
